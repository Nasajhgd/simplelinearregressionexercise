# Simple Linear Regression Practice

This project is a hands-on introduction to simple linear regression using the built-in diabetes dataset from scikit-learn. The notebook uses the standardized BMI feature to predict the dataset's disease-progression target.

## What the notebook covers

- Exploring the dataset and visualizing the feature and target
- Splitting the data into training and test sets
- Fitting and interpreting a linear regression model
- Evaluating predictions with MAE, RMSE, and R-squared
- Comparing the model with a mean-prediction baseline
- Trying other features and comparing a two-feature model

## Getting started

Open `Simple_Linear_Regression_Practice.ipynb` in Jupyter Notebook or JupyterLab and run the cells from top to bottom. The notebook requires Python with NumPy, Matplotlib, pandas, and scikit-learn installed.

## Note

This is an educational example using a small dataset. Its predictions are not medical advice and should not be used for diagnosis or treatment.
